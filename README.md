# Reparto Justo: Gestión de Crisis

## 1. Nombre y frase

**Reparto Justo: Gestión de Crisis**  
Una app de estrategia donde debes distribuir agua, comida y medicinas entre cuatro comunidades en crisis antes de que se agoten los recursos.

## 2. Qué hace y cómo se usa

Distribuye agua, comida y medicinas entre San José, El Rosal, La Paz y Esperanza durante siete días.  
Usa los botones + y − o las teclas 1–4 y las flechas para preparar las asignaciones de cada turno.  
Pulsa «Enviar y avanzar turno» o Enter para aplicar las asignaciones y continuar.

## 3. Enlace para abrirlo

[Abrir Reparto Justo](http://localhost:5173/)  
Enlace local: para abrir la app, primero inicia el servidor con los comandos de la sección siguiente.

## 4. Cómo correrlo en otra máquina

Con Node.js y npm instalados, desde la carpeta del proyecto:

```bash
npm install
npm run dev
```

Abre la dirección que Vite muestre en la terminal (normalmente `http://localhost:5173/`).

Para compilar y probar:

```bash
npm run build
npm test
```
